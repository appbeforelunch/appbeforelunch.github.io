  3. My Claude Code Chrome extension picked the worst deal

    Ep 04 · Chrome extension

    A Chrome extension that shows the real price per ounce on Amazon results and tags the best value. Seven minutes, every test passing, then a "1 lb 11.5 oz" label put the best value tag on the worst deal. A one-sentence bug report fixed it in under four minutes. One search on the real Amazon still crowned a wrong pick. Not affiliated with Amazon.
