Privacy Policy

Last updated October 13, 2026

This website

appbeforelunch.com is a static page hosted on GitHub Pages. It has no accounts, no sign-up forms, no ads and no tracking or analytics scripts. GitHub, as the host, may keep standard server logs; see GitHub's privacy statement. Fonts load from Google Fonts.

App Before Lunch Analytics

App Before Lunch Analytics is a private script the channel uses to read its own YouTube statistics. It is not offered to the public. When the channel owner signs in with Google, the script requests read-only access to YouTube data and YouTube Analytics for that one channel.

  • It reads channel and video statistics such as views, watch time, impressions and click-through rate.
  • The results and the sign-in token are stored only on the channel owner's own computer.
  • Nothing is sold, shared with third parties, used for advertising, or used to train AI models.
  • It never posts, edits or deletes anything on YouTube.

Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
